# 排版组件样式

## 组件

- **标题层级**：字号、字重、颜色、间距
- **引用框**：边框颜色、背景色、内边距
- **列表**：项目符号类型、缩进
- **表格**：表头背景、边框、对齐
- **代码块**：字体、背景、边框圆角

## 硬规则

- 所有组件的样式必须与选定主题一致
- 尺寸要适配手机端（正文不低于 16px 等效）

## 禁止

- 不出现与主题冲突的颜色
- 不用过小的字号
