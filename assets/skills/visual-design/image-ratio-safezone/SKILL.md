# 比例与安全区

## 比例

- **封面**：16:9（公众号分享卡片）或 3:4
- **正文插图**：4:3（横图）或 1:1（方图）

## 安全区

- 四边各留 10%
- 封面左下角不放重要图像元素（微信会叠加标题）
- 手机端预览时封面的上下各 15% 可能被裁切

## 输出

每张图的比例与安全区标注：哪些区域可放重要元素，哪些要留白。

## 硬规则

- 安全区必须逐图标注
- 封面左下角必须干净

## 禁止

- 不忽略手机端裁切风险
- 不把重要元素放在边缘
