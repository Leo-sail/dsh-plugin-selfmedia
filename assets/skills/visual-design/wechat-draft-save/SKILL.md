# 保存公众号草稿

## 保存前必须输出的检查清单

- [ ] 标题已确认
- [ ] 摘要已填写（用于分享卡片）
- [ ] 封面图已设置
- [ ] 正文内容与定稿一致
- [ ] 图片版权来源已记录
- [ ] 事实核查状态已确认
- [ ] 没有明显错别字
- [ ] 没有未删除的临时标注

## 流程

1. 输出上述清单
2. 触发人工确认门，等待用户确认
3. 确认后执行保存

## 硬规则

- **草稿保存和正式发布是两个独立的确认节点，不能合并**
- 本技能只保存草稿，不触发发布
- 清单必须完整输出

## 禁止

- 不在未确认时保存草稿
- 不因用户说"差不多"就跳过确认
