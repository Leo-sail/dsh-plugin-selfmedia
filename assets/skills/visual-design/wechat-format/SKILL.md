# 公众号格式转换

## 规则

- 一级标题：H2，加粗
- 二级标题：H3，加粗，可加左边框装饰
- 引用块：统一使用引用框，不用纯缩进
- 列表：项目符号统一，不混用
- 代码块：等宽字体，浅色背景
- 分隔线：适当使用，不过度

## 硬规则

- 标题层级不跳级
- 列表符号全文统一

## 禁止

- 不混用项目符号样式
- 不在每段之间都插分隔线
