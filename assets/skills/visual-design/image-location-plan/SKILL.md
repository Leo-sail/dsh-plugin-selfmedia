# 配图位置规划

## 规则

- 封面 1 张（必须）
- 正文每 2000 字建议 1-2 张，全文最多 5 张
- 信息密度高的地方（数据、流程、对比）优先配图
- 纯观点段落不必配图

## 输出

图片位置清单（在第几段之后）+ 配图紧迫程度（必须 / 建议 / 可选）。

## 硬规则

- 封面必须有
- 正文图不超过 5 张
- 位置要精确到段落

## 禁止

- 不给纯观点段落硬塞配图
- 不超过上限
