# 风格一致性检查

## 检查项

- 风格基调词是否统一
- 主色调描述是否一致
- 光线氛围是否相近
- 构图密度是否相似
- 如果有人物，同一人物的视觉描述是否一致

## 输出

发现不一致时标出差异并建议统一写法。

## 硬规则

- 逐项对比检查，不能只看一眼
- 差异要指明是哪张图与哪张图

## 禁止

- 不放过主色调不一致
- 不让同一人物在不同图里换长相
