# 图片生成

## 步骤

1. 读取该图的提示词与负面提示词
2. 按指定比例生成（封面 16:9 或 3:4，正文 4:3 或 1:1）
3. 封面与正文插图分别生成
4. 生成后**立即**触发 image-quality-check

## 硬规则

- 比例必须与规划一致
- 每张图生成后立即检查，不要攒到最后

## 禁止

- 不改动已确认的提示词
- 不跳过质量检查
