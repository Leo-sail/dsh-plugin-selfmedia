# 图片提示词生成

## 结构（按此顺序）

1. **风格基调**：flat illustration / photorealistic 等
2. **画面主体和构图**：具体描述画面里有什么
3. **色彩倾向**：主色调、配色方向
4. **光线氛围**：自然光 / 室内 / 逆光等
5. **比例指定**：`--ar 16:9` 等
6. **安全区说明**：`important: leave bottom-left area clear for text overlay`

## 硬规则

- 提示词用英文
- **不在提示词中要求生成中文文字** —— AI 图片模型中文渲染不稳定
- 六项齐全

## 禁止

- 不要求模型画中文
- 不遗漏安全区说明
