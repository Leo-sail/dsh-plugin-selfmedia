# 排版溢出检查

## 检查项

- 图片溢出边框（宽度超过容器）
- 表格过宽（手机端需要横向滚动）
- 标题换行位置奇怪（在标点前换行）
- 代码块不可读（字号过小或超出边界）
- 连续空行超过 2 行
- 长 URL 未折行

## 输出

问题位置列表。

## 硬规则

- 逐项检查，给出具体位置
- 长 URL 必须处理折行或缩短

## 禁止

- 不放过横向滚动
- 不留 3 行以上连续空行
