# 日报发出前校验

## 检查清单

- [ ] 每条资讯的必填字段齐全：标题、链接、来源、发布时间、摘要、用户关注点、关键词、内容状态、评论状态
- [ ] 摘要 ≤100 字，用户关注点 ≤50 字，关键词 1-3 个
- [ ] 链接是合法 URL
- [ ] 内容状态与评论状态均已标注且有说明
- [ ] 用户关注点的来源标注与实际评论状态不矛盾
- [ ] 分类顺序与用户配置一致
- [ ] 末尾统计齐全：总数、各分类数量、事件簇数量、评论可用率

## 重点检查

用户关注点被标为"评论提取"，但该条评论状态不是 `available` 或 `partial` —— 这是最严重的错误，必须打回。

## 输出

- `pass` / `fail`
- 错误列表，指出第几条、哪个字段、什么问题

## 硬规则

- 存在任何问题都不允许发出
- 打回后需说明改哪个字段，不要笼统说"重做"
