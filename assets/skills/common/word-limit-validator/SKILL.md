# 字数校验

## 何时使用

每生成一段受字数约束的文本后立即调用，不要攒到最后一起查。

## 字数上限

| 字段 | 上限 |
|---|---|
| 摘要 | 100 字 |
| 用户关注点 | 50 字 |
| 推荐理由 | 150 字 |
| 方向性标题 | 30 字 |
| 关键词 | 1-3 个 |

## 计数规则

按码点数计。中文与 emoji 各算 1 字。首尾空白不计。

## 输出

- `pass` / `fail`
- 超限项与当前字数
- 超出多少字

## 硬规则

- 校验未通过必须重写，不允许"稍微超一点就放过"
- 重写时删减内容，不是删减标点凑数
- 如果字数上限与事实完整性冲突，优先保证事实完整，并说明超限原因

## 禁止

- 不自行放宽上限
- 不把超限内容截断后当作通过
