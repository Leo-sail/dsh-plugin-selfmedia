# 证据溯源

## 何时使用

每次采集到一条内容后立即建立记录。创作阶段引用任何事实时，都必须能回溯到这里的记录。

## 记录字段

- `content_id`：本条内容的唯一标识
- `original_url`：原始来源地址
- `collected_at`：采集时间戳
- `published_at`：来源自身标注的发布时间
- `content_hash`：正文哈希，用于去重与变更检测
- `used_fragments`：实际使用的原文片段
- `claim_links`：哪条事实来自这条内容
- `is_inference`：该结论是否为推断
- `verified`：是否已核实

## 硬规则

- 每条被引用的事实都必须关联至少一条溯源记录
- 采集时间与发布时间是两个不同的字段，分别填写，不可互相顶替
- 内容哈希使用 SHA-256，对正文归一化后计算
- 同一 URL 内容发生变化时，保留旧记录并新增一条，不覆盖

## 禁止

- 不填写未经确认的发布时间
- 不把推断结论标记为已核实
