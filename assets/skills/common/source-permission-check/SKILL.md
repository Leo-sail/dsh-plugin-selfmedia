# 来源权限检查

## 何时使用

拿到一个待采集的来源（URL、公众号、平台账号）后，在下载任何内容之前调用。先判断权限，再决定采集策略。

## 权限等级

- `full` — 公开可读，正文与元数据均可保存
- `summary_only` — 只能保存标题、摘要、链接，不能落库正文
- `link_only` — 只能保存链接与标题
- `denied` — 明确禁止采集

## 判断步骤

1. 来源是否公开可读，还是需要登录
2. 是否声明了 robots 限制或其等价物
3. 是否需要平台接口授权（如企业账号权限集）
4. 该来源的正文是否允许留档
5. 评论区是否可读

## 输出

- `permission_level`：上述四值之一
- `restriction_notes`：具体限制，逐条说明
- `comment_access`：评论区的可读性，独立于正文

## 硬规则

- 权限等级拿不准时取更保守的一档，不要取更宽的一档
- `summary_only` 与 `link_only` 都必须如实记入 content_status
- 不要因为"技术上抓得到"就判定为允许

## 禁止

- 不绕过登录、验证码或接口风控
- 不把 `denied` 的来源降级成可采集
