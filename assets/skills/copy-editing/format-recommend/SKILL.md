# 格式建议

## 建议时机

| 内容形态 | 建议格式 |
|---|---|
| 步骤清单 | 有序列表 |
| 并列属性对比 | 表格 |
| 技术代码 | 代码块 |
| 值得摘录的金句 | 引用框 |
| 时间线事件 | 时间线格式 |
| 多维度对比 | 对比卡片 |
| 常见问题 | FAQ 格式 |

## 输出

具体位置与理由。**不自动转换格式。**

## 硬规则

- 建议要指明是哪一段、为什么适合
- 不要为了格式而格式

## 禁止

- 不把叙述性内容强行转成表格
- 不自动改动正文
