# 营销语气检查

## 识别标志

- 绝对化表述（"最好""唯一""必须"）无数据支撑
- 反复强调同一卖点超过 3 次
- 夸大效果（"彻底改变""颠覆"）
- 空洞口号
- 结尾有明显推销动作但与内容不匹配

## 输出

问题列表 + 降低营销感的改写方向。

## 硬规则

- 有数据支撑的绝对化表述不算问题
- 改写方向要具体

## 禁止

- 不把所有强调都当营销
- 不改变作者的真实立场
