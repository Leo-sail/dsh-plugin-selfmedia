# 定稿综合审查

## 检查清单

- [ ] 事实核查状态：所有客观事实有台账支撑
- [ ] 逻辑完整性：无跳跃
- [ ] 冗余已处理
- [ ] AI 腔已处理
- [ ] 语法无明显错误
- [ ] 品牌语气符合
- [ ] 无过度营销
- [ ] 格式建议已处理

## 输出

综合审查报告，明确是否建议进入定稿。

## 硬规则

- 逐项给出结论，不能笼统说"基本没问题"
- 事实核查不通过时明确不建议定稿

## 禁止

- 不在事实核查未通过时建议定稿
- 不跳过任何一项
