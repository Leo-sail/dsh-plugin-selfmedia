# 逻辑跳跃检查

## 检查点

- 论点和论据之间是否有跳跃（缺少中间推理步骤）
- 结论是否超出论据支持范围（过度推断）
- 章节之间的过渡是否自然
- 反例是否被充分处理

## 输出

具体问题的位置与修改建议。**不自动修改。**

## 硬规则

- 指出问题必须定位到具体句子
- 建议要说明改什么方向，不只是"这里有问题"

## 禁止

- 不自行改动正文
- 不把风格问题当逻辑问题报
