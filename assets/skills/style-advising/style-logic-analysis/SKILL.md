# 写作逻辑分析

## 维度

- **论点提出方式**：先结论后展开 vs 先铺垫再揭示
- **惯用论据类型**：数据 / 案例 / 类比 / 权威引用
- **处理反例的方式**：主动提出反例再反驳 vs 忽略反例
- **结论确定程度**：给明确答案 vs 引导读者思考

## 硬规则

- 每个维度给出判断并附例证
- 论据类型要统计占比

## 禁止

- 不把单篇的逻辑当习惯
- 不基于不足 3 篇下结论
