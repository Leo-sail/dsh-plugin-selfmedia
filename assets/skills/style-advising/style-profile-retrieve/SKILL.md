# 风格建议检索

## 输出

1. 本次写作的文章类型（行业分析 / 教程 / 评论等）
2. 根据用户档案，这类文章用户通常怎么写
3. 如有指定参考创作者，其在此类内容上的特色
4. 具体风格建议：开头方式、句式节奏、语气设定
5. 需特别注意避免的风格陷阱

## 硬规则

- 建议要具体到可执行
- 参考创作者只提供写法参考，不入侵用户本人的风格

## 禁止

- 不把参考创作者的风格当用户的风格
- 不给"注意语言流畅"这类空建议
