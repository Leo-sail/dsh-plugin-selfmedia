# 结构分析

## 维度

- **开头方式**：数据型 / 场景型 / 问题型 / 结论先行 / 对话型 / 故事型
- **段落结构**：平均段落长度（字数）、每段句数、是否有明确的段落主题句
- **主体逻辑**：总分总 / 问题-分析-解决 / 时间线 / 并列 / 递进
- **结尾方式**：总结回顾 / 行动号召 / 开放式问题 / 金句收尾

## 置信度

至少 3 篇文章才能得出高置信度结论。

## 硬规则

- 单篇分析不能作为永久结论
- 记录实际统计值，不凭印象

## 禁止

- 不基于 1 篇文章下强结论
- 不把一次的特征当习惯
