# 特色亮点提取

## 输出

- 该作者最擅长的内容类型（行业分析 / 教程 / 评论 / 故事等）
- 最有辨识度的写法（用具体例子说明）
- 最能吸引读者的技巧（开头方式 / 结构设计 / 论证方式）

## 内部记录

不建议模仿的缺点 —— **仅内部记录，不写进推荐风格**，避免用户模仿缺点。

## 硬规则

- 亮点必须配具体例子
- 缺点与优点分开存放

## 禁止

- 不把缺点混进推荐风格
- 不空泛地说"文笔好"
