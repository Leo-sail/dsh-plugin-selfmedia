# 语法习惯分析

## 维度

- 句子平均长度（字数范围）
- 短句（≤15 字）/ 中句（15-30 字）/ 长句（>30 字）比例
- 常用标点习惯：破折号 / 省略号 / 感叹号的使用频率
- 主动句 / 被动句比例
- 常用连接词排名（前 5 个）
- 口语词使用频率（"其实""说白了""你懂的"等）

## 硬规则

- 比例要基于实际计数
- 连接词排名要给出频次

## 禁止

- 不凭印象列连接词
- 不把偶发用词当习惯
