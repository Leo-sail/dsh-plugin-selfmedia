# 语气风格分析

## 输出字段

- **正式程度**：1（极度口语）— 5（非常正式）
- **亲和力**：1（冷静客观）— 5（热情投入）
- **观点表达**：1（克制含蓄）— 5（直接犀利）
- **与读者距离**：惯用"你 / 我们"还是第三人称
- **情绪密度**：1（全程理性）— 5（有情绪起伏）

## 硬规则

- 每个维度给出分值并附证据
- 人称习惯要统计出现频次

## 禁止

- 不给没有证据的分数
- 不混淆作者本人的语气与引用他人的语气
