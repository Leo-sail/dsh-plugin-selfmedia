# 风格档案更新

## 合并规则

- 新结果与已有内容**合并，不覆盖**，保留演进轨迹
- 一篇文章的分析**不能改变置信度超过 0.1**
- 档案达到 3 篇以上分析 → `confidence > 0.7`
- 达到 8 篇以上 → `confidence > 0.85`

## 每次更新记录

- 更新时间
- 本次分析的文章数量
- 置信度变化

## 硬规则

- 置信度按篇数门槛提升，不能跳级
- 保留历史版本，不删旧结论

## 禁止

- 不基于一篇文章给出高置信度
- 不用新结论覆盖旧结论
