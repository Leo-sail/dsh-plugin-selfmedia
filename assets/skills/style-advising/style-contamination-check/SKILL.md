# 风格污染检查

## 检查方式

对照各参考创作者的特有表达方式，检查成稿中是否出现：
- 特定句式
- 惯用词
- 独特的论证方式

## 输出

发现疑似"风格污染"时，标注具体位置并说明来源（哪个创作者）。

## 硬规则

- 必须对照具体创作者档案，不是凭感觉
- 污染位置要精确到句

## 禁止

- 不把通用表达当某人的专属风格
- 不放过明显的整段模仿
