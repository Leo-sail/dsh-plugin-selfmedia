# 创作角度生成

## 角度类型

- 新闻解读：这件事意味着什么
- 教程型：用户可以怎么做
- 案例分析：这件事给我们什么启发
- 争议分析：争论的本质是什么
- 行业趋势：这是更大趋势的一部分吗
- 实操清单：可以直接用的方法
- 避坑指南：常见错误和误区
- 对比分析：和类似事物有什么不同
- 观点评论：作者自己的判断

## 每个角度输出

- 一句话说明切入点
- 适合的体裁
- 预计所需资料的充分程度

## 硬规则

- 每条资讯至少 3 个角度
- 角度之间必须有实质差异，不能是同一个意思换说法

## 禁止

- 不生成自己写不了的角度（资料明显不够）
- 不把同一切入点拆成两个角度凑数
