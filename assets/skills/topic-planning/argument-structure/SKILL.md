# 论点结构

## 每章展开

- **核心分论点**：一句话
- **支撑论据**：至少 1 个，注明来自哪条资讯或台账记录
- **潜在反例**：如果存在
- **对反例的回应**：怎么处理
- **过渡钩子**：怎么接到下一章

## 硬规则

- 每个分论点必须有论据支撑
- 论据必须能追溯到事实台账
- 论据不支持的分论点要么删掉，要么降级为推测

## 禁止

- 不留没有论据的论点
- 不忽略明显存在的反例
