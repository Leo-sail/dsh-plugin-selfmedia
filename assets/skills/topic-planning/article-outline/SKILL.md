# 文章大纲

## 必含内容

- **核心论点**：一句话
- **目标读者画像**：谁会读这篇文章
- **主线逻辑**：总分总 / 问题-分析-解决 / 时间线 / 递进
- **章节列表**：每章标题 + 该章要解决的问题 + 建议字数比例
- **外部资料清单**：交给情报分析处理
- **预计字数范围**

## 硬规则

- 字数比例之和应为 100%
- 每章必须回答一个明确的问题
- 资料清单要具体到"需要核实什么"，不是"补充背景"

## 禁止

- 不生成没有论点的结构空壳
- 不把大纲写成目录
