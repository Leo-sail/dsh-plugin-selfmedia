# 体裁判断

## 判断依据

| 内容特点 | 建议体裁 |
|---|---|
| 信息密度高、逻辑严密 | 公众号长文 |
| 情绪钩子强、分享欲高 | 小红书 |
| 步骤清晰、操作性强 | 教程 / 清单型 |
| 观点犀利、有争议空间 | 评论型 |
| 适合口语表达 | 视频口播稿 |
| 内容够两个平台 | 公众号 + 小红书双发 |

## 输出

- `format_recommendation`
- `rationale`：为什么

## 硬规则

- 给出建议但不强制
- 理由要具体到内容特征，不是体裁的通用优点

## 禁止

- 不所有内容都建议同一个体裁
- 不跳过分析直接给结论
