# 初稿事实对应检查

## 逐段检查

- 每个客观数据是否有对应来源
- 每个引用是否准确
- 每个结论是否在资料范围内
- 有没有为了让文章完整而无意添加的未核实事实

## 发现问题时

- 标记具体位置
- 说明缺少什么证据
- 返回给文案创作处理（删除 / 改为推测性表述 / 请情报分析补充核实）

## 输出

`evidence_check_report`：通过 / 不通过 + 问题列表

## 硬规则

- 每个客观陈述都要能对应到台账
- 无支撑的必须处理，不能放过

## 禁止

- 不因为"看起来合理"就判定通过
- 不自行修改初稿
