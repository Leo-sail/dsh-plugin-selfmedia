# 评论分析

## 前置条件

评论状态必须是 `available` 或 `partial`。其他状态一律不执行。

## 提取内容

- **核心疑问**：什么问题被反复问
- **主要反对意见**：用户不认同什么
- **情绪倾向**：正面 / 负面 / 中性 / 混合
- **用户补充信息**：正文没有但评论提到的重要内容
- **未被回答的问题**：正文没回应、用户还在追问的

## 输出

- `comment_themes`
- `sentiment`
- `unresolved_questions`

## 硬规则

- 提取的每条内容都必须是评论里真实出现的
- 只有零星几条评论时，说明样本量小，不要给出强结论

## 禁止

- **评论不可获取时，绝对禁止执行本技能**
- 不把正文内容推断成评论观点
- 不把单条评论的情绪概括为整体情绪
