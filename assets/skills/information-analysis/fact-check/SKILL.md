# 事实核查

## 状态标记

| 状态 | 含义 |
|---|---|
| `confirmed` | 至少 2 个独立来源一致 |
| `partially_confirmed` | 只有单一来源 |
| `inferred` | 由其他事实推断得出 |
| `disputed` | 来源之间存在矛盾 |
| `unverified` | 未找到可信来源 |

## 硬规则

- 单一来源**不能**标 confirmed
- 推断必须标 inferred，不能标 confirmed
- 无法核实的事实必须主动告知编辑总监
- 独立来源指互不转载的来源，同一篇稿子的多个转载不算独立

## 禁止

- 不为了文章完整性降低核实标准
- 不静默跳过无法核实的关键事实
