# 事件聚合

## 合并条件

同时满足：
- 时间窗口内（默认 72 小时）
- 主体相同
- 事件相同

## 输出

- 事件名称
- 涉及资讯列表（附各自链接）
- 各来源的不同报道角度
- 争议点（不同来源事实有出入时）
- 综合摘要，注明来源数量

## 硬规则

- 同一主体的不同事件不合并
- 事实有出入时必须标注争议，不取"多数说法"
- 争议未解决时如实呈现两种说法

## 禁止

- 不为减少条目数强行合并
- 不在未解决争议时选一个说法作为事实
