# 事实台账

## 记录字段

- 事实内容（一句话）
- 来源 URL（至少 1 个）
- 来源类型
- 发布时间
- 核实状态
- 核实时间

## 归档方式

按选题或文章 ID 归档，文案创作时按 ID 查询。

## 硬规则

- **没有台账记录的客观事实不能进入文章正文**
- 每条事实至少一个来源
- 台账随文章一起留档，便于事后追溯

## 禁止

- 不在台账里记录未经核实的内容后标记为 confirmed
- 不省略来源链接
