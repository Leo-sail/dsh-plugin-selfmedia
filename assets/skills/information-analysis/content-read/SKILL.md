# 单条资讯阅读

## 提取内容

- **主要事件或观点**：这条资讯在说什么
- **涉及主体**：人物、公司、产品名
- **关键数据**：数字、比例、金额、版本号
- **时间节点**：事件发生时间、公告时间
- **文章立场**：报道 / 评论 / 教程 / 公告 / 研究

## 阅读顺序

1. 先读标题与来源，判断基本分类与可信度
2. 再读正文，提取核心观点与关键数据
3. 最后读评论区，提炼用户真实反应

## 硬规则

- 只提取原文出现的信息，不补充背景知识
- 观点与事实分开记录
- 无法确定的立场标为"不明"，不要猜

## 禁止

- 不在此环节做价值判断
- 不把评论内容混入正文提取结果
