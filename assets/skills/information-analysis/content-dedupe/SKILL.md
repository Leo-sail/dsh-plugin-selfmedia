# 资讯去重

## 两级去重

1. **精确去重**：内容哈希完全相同 → 保留一条
2. **模糊去重**：语义相似度 ≥85% → 保留最完整的一条，其余标记为重复并附参考链接

## 事件簇

同一事件的多条不同来源报道**不删除**，聚合为一个事件簇：
- 事件名称
- 涉及的全部来源链接
- 各来源的不同报道角度
- 综合摘要，注明"综合 N 个来源"

## 输出

- `dedupe_report`：删了什么、为什么
- `event_clusters`：事件簇列表

## 硬规则

- 去重只删重复，不删来源
- 同一事件的报道即使措辞完全不同，也要聚合
- 语义相似的判断要看事件主体与核心事实，不是看标题像不像

## 禁止

- 不因标题相似就判定重复
- 不删除事件簇中的任何来源链接
