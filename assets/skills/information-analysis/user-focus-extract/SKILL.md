# 用户关注点提取

## 要回答的问题

"如果把这条资讯发到我的用户群，用户最可能讨论什么？"

## 来源标注（强制）

- `[正文推断]` —— 评论不可用时，只能基于正文推测读者会关心什么
- `[评论提取]` —— 从真实评论中提炼
- `[综合]` —— 两者结合

## 字数

≤50 字，硬上限。

## 硬规则

- 评论状态不是 `available`/`partial` 时，只能标 `[正文推断]`
- 标注必须与实际使用的材料一致

## 禁止

- **禁止把正文推断标注为评论提取** —— 这是整个流程最严重的造假
- 不写空泛的"用户可能会关注相关进展"
